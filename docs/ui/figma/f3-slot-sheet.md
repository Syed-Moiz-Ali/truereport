# F3 slot sheet — Figma elements that cannot be shown as drawn (Workshop Admin screens 1–12)

**Project:** TrueReport
**Phase:** F3-0 Step 2 (gap analysis only — no build, no server/data change)
**Date:** 6 November 2026
**Rule applied (owner decisions O3–O10 + master.md §1–2 locked rules):** every Figma element keeps the Figma slot, size, style, colour and position. Only text or data that would be false or unsafe under locked product rules may change, and the change is a **same-slot neutral replacement in the exact style** — never a hide, unless the element is unsafe and has no neutral form. Where the owner has not decided, the default is **Option A**. Nothing was silently removed. This sheet records what *would* need to change if the screens were built; F3-0 makes no code or server change.
**Locked rules enforced:** no manager/review/approval/sign-off/second-person review (master.md §1–2); no certification/verified/compliance/score/GPS claims; no sample people/vehicles/photos/plates as data; no customer app/portal; no payments; C0 account model (Platform Admin creates Workshop Admins; Workshop Admin creates Technicians own-workshop only, admin-set password, no invitations/pending); light-only; ARB-only text.
**O-rules enforced in recommendations:** O3 1280 px as drawn, tablet/phone derived + labelled; O4 dashboard from existing data only; O5 Add Staff = Create Technician (C0); O6 no review/approve wording; O7 builder within existing template rules; O8 deactivation keeps reason+audit, copies-can't-be-recalled wording; O9 our report/PDF, same allowlist; O10 settings only where they exist.

**Screen numbering:** this sheet uses prompt screens 1–12 (1 Dashboard, 2 Live Job Queue, 3 Create/Schedule, 4 Assign Technician, 5 Staff Management, 6 Add Staff, 7 Template List, 8 Template Builder, 9 Report Viewer, 10 Share-Link Deactivation, 11 Settings, 12 PDF Preview). Export folders are offset from screen numbers — see folder↔screen map below.
